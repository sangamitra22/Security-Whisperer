# Security Whisperer

A production-ready static website for Security Whisperer, a practical secure-by-design architecture framework with principles, patterns, controls, guardrails, automation, and continuous assurance.

## Live Website

After GitHub Pages is enabled, the site is available at:

https://sangamitra22.github.io/Security-Whisperer/

## Files

- `index.html` - complete single-page website with inline CSS and accessible SVG diagrams.
- `Sanga_pic.jpeg` - profile image used in the About Me section.
- `robots.txt` - crawler entry point for the published site.
- `.nojekyll` - keeps GitHub Pages serving static files directly.
