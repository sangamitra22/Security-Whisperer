# Security Whisperer

A production-ready static website for Security Whisperer, a practical secure-by-design architecture framework with principles, patterns, controls, guardrails, automation, and continuous assurance.

## Live Website

After GitHub Pages is enabled, the site is available at:

https://sangamitra22.github.io/Security-Whisperer/

## Files

- `index.html` - complete single-page website with inline CSS, accessible navigation, metadata, and SVG diagrams.
- `Sanga_pic.jpeg` - profile image used in the About Me section.
- `404.html` - friendly not-found page for GitHub Pages.
- `robots.txt` - crawler entry point for the published site.
- `sitemap.xml` - sitemap for the published site.
- `.nojekyll` - keeps GitHub Pages serving static files directly.

## Publish With GitHub Pages

1. Open repository Settings.
2. Select Pages.
3. Set Source to Deploy from a branch.
4. Select branch `main` and folder `/ (root)`.
5. Save and wait for the deployment to finish.

Enable HTTPS enforcement in GitHub Pages settings once GitHub makes the option available.
